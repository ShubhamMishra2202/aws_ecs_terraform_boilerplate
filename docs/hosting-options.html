    Assumptions

    • Prices go stale. These are us-east-1 on-demand list prices checked in Oct 2026. Check the AWS pricing pages before quoting them.
    • Fargate x86: $0.04048 per vCPU-hour, $0.004445 per GB-hour, 730 hours a month.
    • Public IPv4: $3.65 per address per month, including dynamic IPs. An ALB holds 2.
    • ALB: $16.43 fixed plus about $1.60 of capacity units at low traffic.
    • API Gateway HTTP API: $1 per million requests. Cloud Map adds $0.10 per registered task.
    • NAT: t4g.nano instance with 8 GB disk is $3.71. A NAT Gateway is $32.85 plus data, about $34.
    • RDS PostgreSQL gp3: micro 20 GB $14, small 50 GB $29, small Multi-AZ $58.
    • CloudWatch: first 10 alarms are free. Logs about $1 a month at low volume. Container Insights about $7.
    • EC2 baseline: t3.small $15.18, 15 GB gp3 $1.20, one public IP $3.65. Uses the default VPC. Caddy provides free HTTPS.
    • Not included: an external database plan, third-party APIs, and data transfer beyond the free 100 GB.
